# هنذاكروا | Hanzakro

تطبيق Android عربي مبني بـ Expo وReact Native وTypeScript مع Expo Router. عند كل تشغيل بارد يعرض التطبيق الدعاء المرتبط بالهوية المحفوظة، ثم ينتقل إلى شاشة اختيار المنصة. إذا لم تُحدد الهوية من قبل، تظهر شاشة اختيار الهوية مرة واحدة قبل الدعاء. تعرض شاشة الاختيار عبارة «تعي برجلك اليمين ده سيستم كامل عشان نجيب 91٪» وخيارَي «هنذاكروا Portal» و«هنذاكروا V1». الضغط على أي خيار يحفظه ويفتح المنصة داخل WebView في التطبيق؛ زر «الرئيسية» يعيد المستخدم إلى خيارات المنصة. الأيقونة مضمنة محليًا في `assets/icon.png`.

## المتطلبات والتشغيل

استخدم Node.js 22 وpnpm 11. ثبّت الحزم من ملف القفل ثم شغّل خادم التطوير:

```bash
pnpm install --frozen-lockfile
pnpm start
```

يحتاج المشروع إلى Android development build بسبب وحدات التعرف على الكلام الأصلية؛ Expo Go وحده لا يثبت دعمها. بعد إعداد Android SDK محليًا:

```bash
pnpm android
```

## الفحوص

```bash
pnpm test
pnpm typecheck
pnpm lint
pnpm run check:expo
pnpm exec expo install --check
```

تتضمن الاختبارات مسارات الدعاء والهوية وخيارَي المنصة، والتحقق من وجهتيهما، والتأكد من أن شاشة الاختيار لا تضمّن عنوان موقع ظاهرًا بداخلها.

## بناء APK عبر EAS

المستودع مربوط بمشروع EAS عبر `extra.eas.projectId` في `app.json`. يضبط `eas.json` ملفات `development` و`preview` و`apk` لإنتاج APK داخلي، و`production` لإنتاج AAB. بعد تسجيل الدخول إلى Expo وضبط بيانات التوقيع في EAS:

```bash
pnpm eas:whoami
pnpm eas:build:apk
```

لإنشاء AAB إنتاجي:

```bash
pnpm dlx eas-cli@latest build --platform android --profile production
```

فحص EAS في بيئة التنفيذ الحالية أعاد `Not logged in`، كما لا يوجد Android SDK محلي؛ لذلك لم يُنشأ APK/AAB ولم يُختبر على هاتف. لا تضع رمز Expo أو مفتاح توقيع في Git أو المحادثة. لا يحتوي المستودع على أسرار أو مفاتيح توقيع.

## الوظائف والحدود

يدعم الإصدار الحالي عرض الدعاء عند كل تشغيل بارد ثم اختيار Portal أو V1، وفتح البوابة داخل WebView، والرجوع إلى شاشة الخيارات، وإعدادات الهوية والدعاء، وإشعار ترحيب محلي بعد اكتمال الإعداد وموافقة النظام، وحالات تحميل وأخطاء وتنقل وأدوات تحكم. جسر Web Speech مقصور على أصل المنصة المختارة. يحتاج تشغيل الصوت والتعرف عليه والفيديو وملء الشاشة إلى تجربة على development build وجهاز Android حقيقي؛ فهي تعتمد على الجهاز وخدماته والموقع.

لا يتجاوز التطبيق تسجيل الدخول أو حماية المحتوى ولا ينزّل الفيديوهات المحمية. وضع Kiosk الحقيقي وإشعارات Web Push غير مفعلين. راجع [TODO.md](TODO.md) و[مصفوفة التحقق على Android](docs/verification-matrix.md) و[الملاحظات التقنية](docs/technical-notes.md) لمعرفة ما نجح آليًا وما ينتظر تجربة الهاتف.
